---
description: A one-stanza pirate's poem about the current working directory
argument-hint: "[directory]"
---
Look at what is in ${@:-the current working directory} (list it; do not read
file contents). Then write exactly one stanza, four to six lines, about what
you found, in a style a pirate would appreciate. Name at least two real
things that are actually there. Nothing after the stanza.
